# Instalar y poner en marcha Python para IA

## 1) Instalar Python, pip y entornos virtuales

Copia y pega este comando en la terminal:

```bash
sudo apt update && sudo apt install -y python3 python3-pip python3-venv nano
```

Este comando instala Python en su última versión, además de:

- `python3-pip`: para instalar librerías externas
- `python3-venv`: para crear entornos virtuales
- `nano`: un editor de texto para trabajar desde la terminal

## 2) Ejecutar un archivo Python

Para ejecutar cualquier archivo `.py`, usa este formato:

```bash
python3 nombre_del_archivo.py
```

Ejemplo:

```bash
python3 mi_script.py
```

> Recuerda reemplazar `nombre_del_archivo.py` por el nombre real de tu archivo.
